# Student Record Management System (C)

A console-based Student Record Management System written in C.
The project uses structures and file handling to store student data permanently.

## Features
- Add student records
- View all students
- Search by roll number
- Update student details
- Delete student records
- Data persistence using binary files

## Concepts Used
- Structures
- File handling (`fopen`, `fread`, `fwrite`)
- Modular programming
- Searching and sorting

## How to Compile and Run
```bash
gcc main.c student.c -o student
./student
